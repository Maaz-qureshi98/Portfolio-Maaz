# Maaz Qureshi: Portfolio

**Live site:** https://maaz-qureshi98.github.io/Portfolio-Maaz/

Personal portfolio of a Research Engineer in Embodied AI and robot learning: learned policies (RL, VLA, imitation), multimodal perception, and real-world multi-robot systems.

## Sections
- **About:** background, University of Waterloo MASc, and research collaborations
- **Research:** VLA and diffusion-policy rollouts on cobots, CRADMap, RAPTAR, Swarm Autobots, underwater inspection and more
- **Journey:** timeline of roles and education
- **Contact:** email, LinkedIn, Google Scholar

## Structure
| File | Purpose |
|---|---|
| `index.html` | Page content |
| `style.css` | Main styles, light/dark theme |
| `mediaqueries.css` | Responsive layout |
| `script.js` | Theme toggle and mobile menu |
| `assets/` | Images, logos and CV |
